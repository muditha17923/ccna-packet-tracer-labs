
# CCNA Packet Tracer Labs

A collection of Cisco Packet Tracer labs created while preparing for the CCNA.

## Topics

- Network Fundamentals
- VLANs
- Trunking
- STP / RPVST+
- EtherChannel
- Inter-VLAN Routing
- Static Routing
- OSPF
- IPv6
- DHCP
- NAT
- ACLs
- Port Security
- DHCP Snooping
- Wireless
- Troubleshooting
